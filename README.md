# Earthquake Damage Prediction Using Machine Learning

## Project Overview

This project focuses on predicting earthquake-related building damage using machine learning classification techniques.

The project involves exploring the earthquake dataset, preprocessing the data, performing exploratory data analysis, training classification models, and evaluating their performance.

## Objectives

The main objectives of this project are:

- Understand the earthquake damage dataset
- Perform data cleaning and preprocessing
- Explore the dataset using exploratory data analysis
- Identify important features related to building damage
- Prepare the data for machine learning
- Train classification models
- Evaluate the performance of the models
- Predict earthquake-related building damage

## Dataset

This project uses two training datasets:

### train_values.csv

This file contains the input features describing the buildings and their characteristics.

### train_labels.csv

This file contains the target variable representing the level of damage suffered by the buildings during the earthquake.

The two datasets are linked using a common building identifier and are used together for training machine learning classification models.

## Project Workflow

The project follows these major steps:

1. Import required libraries
2. Load the dataset
3. Understand the dataset
4. Perform data cleaning
5. Perform exploratory data analysis
6. Prepare features and target variables
7. Split the data into training and testing sets
8. Train machine learning classification models
9. Evaluate model performance
